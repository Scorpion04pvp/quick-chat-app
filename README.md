# ONYX CHAT 🔮💬🎬

تطبيق تواصل اجتماعي ومحادثات راقية مشفرة بتصميم بنفسجي فاخر (Luxury Neon Purple) مستوحى من شعار **ONYX CHAT**.

---

## 🌟 أبرز مميزات التطبيق:

1. **الهوية البصرية وشعار ONYX:**
   - تصميم عصري بلمسات نيون بنفسجية فاخرة وخلفية داكنة مريحة للعينين.
   - شعار رسمي أنيق وتناسق كامل في كافة الواجهات.

2. **التسجيل الذكي والتحقق بالكود:**
   - خيار التسجيل عبر البريد الإلكتروني (Gmail) أو رقم الهاتف.
   - نظام إرسال كود تحقق فوري (Verification Code) والتأكيد للدخول.
   - حماية كاملة للحسابات بكلمة مرور مشفرة.

3. **المحادثات المشفرة والمحمية:**
   - محادثات فورية في الوقت الفعلي بتقنية WebSockets.
   - إرسال الرسائل النصية، الصور، والفوكال (الرسائل الصوتية مع عداد وموجات صوتية).
   - إمكانية حذف أي رسالة خاصة بك داخل المحادثة.
   - مكالمات صوتية (Audio Calls) ومكالمات فيديو (Video Calls) عالية الدقة.

4. **قسم الريلز والفيديوهات (Reels):**
   - منصة مخصصة لنشر ومشاهدة مقاطع الفيديو القصيرة (Reels).
   - التفاعل بوضع قلب (Like)، كتابة تعليقات، ومشاركة الريلز في المحادثات.
   - متابعة الناشرين (Follow / Followers).
   - تحكم كامل لصاحب الفيديو لإدارته وحذفه في أي وقت.

5. **الملف الشخصي المتكامل (User Profile):**
   - معرف فريد لكل حساب (User ID) مع زر نسخ سريع.
   - إحصائيات المتابعين ومن تتابعهم.
   - قسم خاص بالفيديوهات التي وضعت لها قلب (Liked Reels) يظهر لك وحدك.
   - تبديل لغة التطبيق بسهولة بين العربية (RTL) والإنجليزية (LTR).
   - تخصيص الثيم وخلفية المحادثة.

---

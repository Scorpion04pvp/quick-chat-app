# تطبيق المحادثات السريعة (Chat, Photos & Vocals) 💬🎙️📸

تطبيق محادثات متكامل يعمل في الوقت الفعلي (Real-Time) بواسطة **Node.js** و **Socket.IO** مع واجهة مستخدم عصرية وسريعة.

---

## 🌟 مميزات التطبيق

1. **تسجيل الدخول البسيط:**
   - كتابة الاسم / اللقب.
   - اختيار صورة جاهزة (أفاتار) أو رفع صورتك الخاصة من الجهاز.
2. **إضافة جهات الاتصال والتواصل المباشر:**
   - زر خاص لإضافة أي شخص بمجرد كتابة اسمه المستعار.
   - محادثات فردية خاصة (1-on-1 Chat).
   - غرفة عامة (الغرفة العامة) للدردشة المباشرة مع جميع المتواجدين.
   - مؤشر حالة الاتصال (متصل الآن باللون الأخضر / غير متصل).
3. **الوسائط والرسائل الصوتية (الفوكال):**
   - إرسال رسائل نصية فورية.
   - إرسال صور مباشرة مع إمكانية تكبيرها وعرضها بدقة كاملة.
   - **تسجيل وإرسال رسائل صوتية (فوكال - Vocal):**
     - عداد زمني للتسجيل وموجات صوتية متحركة.
     - إمكانية الإلغاء أو الإرسال.
     - مشغل صوتي مدمج داخل فقاعة المحادثة للتحكم في التشغيل والتقديم.

---

## 🚀 تشغيل التطبيق محلياً على جهازك

1. افتح موجه الأوامر (Terminal / PowerShell) داخل مجلد المشروع:
   ```bash
   cd chatapp
   ```

2. تشغيل السيرفر:
   ```bash
   npm start
   ```

3. افتح المتصفح على الرابط:
   [http://localhost:3000](http://localhost:3000)

> **ملاحظة:** يمكنك فتح نافذتين (أو متصفحين مختلفين)، وإنشاء اسمين مختلفين وتجربة إضافة بعضهما والتحدث وإرسال الصور والفوكال فوراً!

## 🌐 نشر التطبيق على نطاق مجاني (Free Domain)

للحصول على رابط مجاني ينتهي بـ `onrender.com` أو ما شابه ومشاركته مع أصدقائك:

### الطريقة الأولى: عبر منصة Render (موصى بها ومجانية 100%):
1. توجه إلى [https://render.com](https://render.com) وسجل دخولك باستخدام حسابك على GitHub.
2. اضغط على زر **New +** ثم اختر **Web Service**.
3. اختر مستودع هذا المشروع من قائمتك في GitHub.
4. الإعدادات المطلوبة:
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
5. اضغط **Deploy Web Service**.
6. خلال دقيقة ستحصل على نطاق مجاني مع شهادة أمان مشفرة (HTTPS) مثل:
   `https://my-chatapp.onrender.com`

> **أهمية HTTPS:** يوفر النطاق المشفر HTTPS الصلاحية للمتصفحات والهواتف لتشغيل الميكروفون وتسجيل الفوكال بحرية تامة على أي هاتف أو حاسوب!
